# color-slide

ชุดธีมสีสำหรับสไลด์ PowerPoint Canva และเอกสาร Word 30 ธีม คัดลอกไปใช้ได้ฟรี

**ดูและคัดลอกสีออนไลน์:** https://tool.9nano.net/color-slide/

## ทำอะไรได้บ้าง

- **ดูหน้าตาจริงก่อนเลือก:** ทุกธีมแสดงสไลด์ 2 หน้า (หน้าเปิดและหน้าเนื้อหา) คู่กับเอกสาร Word 1 หน้า ใช้เนื้อหาเดียวกันทุกธีม จึงเทียบเฉพาะสีและสไลด์ได้ตรงๆ
- **คลิกคัดลอกสี:** คลิกแผ่นสีหรือรหัสสีของธีมไหนก็ได้ (เช่น หลัก `0B8A74`) เพื่อคัดลอกรหัสไปตั้งสีใน PowerPoint หรือ Canva ได้ทันที
- **วางใน prompt ให้ AI สร้างให้:** คัดลอกบล็อกสีของธีมที่ชอบไปวางใน prompt สร้างสไลด์ ไม่ต้องให้ AI เลือกสีเอง

## หมวดของธีม

| หมวด | ธีม | ลักษณะ |
|---|---|---|
| T ธีมหลัก | T1–T10 | พื้นสว่าง สีสมดุล (T8–T10 ดึงสีจากสไลด์ตัวอย่าง) |
| S เพิ่มเติม | S1–S5 | พื้นสว่าง โทนสดใหม่ |
| P พาสเทล | P1–P5 | สีหลักอ่อนนุ่ม ตัวอักษรบนสีหลักเป็นสีเข้ม |
| H High Contrast | H1–H5 | สีตัดกันสูง อ่านชัดบนจอโปรเจกเตอร์ |
| D Dark | D1–D5 | พื้นมืดทั้งหน้าเปิดและหน้าเนื้อหา |

## วิธีใช้ธีมกับ prompt

1. เปิดหน้าตัวอย่าง เลือกธีมที่ชอบ
2. เปิด [slide-color-themes.md](slide-color-themes.md) ไปที่หมวดของธีมนั้น แล้วคัดลอกบล็อกใน "บล็อกพร้อมวาง"
3. ใน [slide-prompt-concept-explainer.md](slide-prompt-concept-explainer.md) ข้อ 2 (สี) วางแทน 3 บรรทัดที่ขึ้นต้นด้วย "ค่าเริ่มต้น:" ไปจนถึง "…โดยคงบทบาทสีครบเหมือนเดิม"
4. เอกสาร Word ที่สร้างจากสไลด์ ([word-prompt-companion-doc.md](word-prompt-companion-doc.md)) จะอ่านสีจากไฟล์สไลด์เอง ไม่ต้องกำหนดซ้ำ

ถ้าไม่วางบล็อกสี prompt จะใช้ธีม T2 (ฟ้า–เหลืองอำพัน) เป็นค่าเริ่มต้น

ธีมหมวด D เป็นโหมดมืด ถ้าต้องการเอกสาร Word พื้นขาวสำหรับพิมพ์ ให้ระบุใน prompt เอกสารเพิ่มว่า "พื้นหน้ากระดาษขาว ใช้เฉพาะสีหลักและสีเน้นของธีม"
